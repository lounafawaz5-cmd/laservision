# Video Editing Guide (both accounts)

Source: `brand/Video_Editing_Guide.pdf` (sent by Luna, dated Oct 8, 2026). **Read this before editing any reel.**
Settings come from CapCut; the Remotion captions (`reels/src/components/Captions.tsx`) recreate them.
Both accounts share everything below except the glow color.

## Captions
| Setting | Value |
|---|---|
| Font | **Montserrat Arabic Bold** (covers English and Arabic). File: `reels/public/fonts/Montserrat-Arabic-Bold.ttf` (OFL) |
| Template | **Word-by-word fade** |
| Text color | White |
| Box | None |
| Glow | On, standard preset (not premium), **intensity 30, range 58** |
| Glow color | LaserVision **#005D83** · ZEISS VISION CENTER **#0C188D** |

All on-screen text uses Montserrat Arabic Bold. ZVC overlay marks (!!, ?, ticks, icons) use **#0C188D** with a white outline.

## Transitions (only these four)
| Transition | Access | Use |
|---|---|---|
| Mix | Free | Soft crossfade, the default between clips |
| Echo Fade | CapCut Pro | Premium |
| Film Reject | Free | Film-style flash for energetic or reveal moments |
| Acrylic Fades | Free | Frosted fade for calm, clinical moments |

## Checklist before export
- [ ] Captions in Montserrat Arabic Bold, word-by-word fade
- [ ] Glow on, intensity 30, range 58
- [ ] Glow #005D83 (LaserVision) or #0C188D (ZVC)
- [ ] Transitions only Mix, Echo Fade, Film Reject, Acrylic Fades
- [ ] Sound effects only the four above
